HOW TO EMBED YOUR PDF CV ON GITHUB PAGES

1. Open https://github.com/qvtrtran/qvtrtran.github.io
2. Upload cv.html and Quang_Van_Tran_Public_CV.pdf into the repository ROOT folder, replacing cv.html.
3. Commit changes.
4. Open https://qvtrtran.github.io/cv.html after the Pages deployment completes.

WHAT THIS DOES
- The CV tab now displays the PDF inside the page, rather than an HTML summary.
- View PDF and Download PDF links remain available (mobile browser fallback).
- No changes to index.html or publications.html.

IMPORTANT
- Included PDF is the previously prepared 2-page public academic CV, NOT your original longer CV.
- It omits your home address and personal phone number.
- It still contains submitted manuscripts in the CV.
- To use your own full updated PDF, replace Quang_Van_Tran_Public_CV.pdf with that PDF, keeping the same filename. Review the PDF carefully for private contact details before publishing.
