QUICK UPLOAD (no HTML editing)
1. Extract the ZIP file on your computer (do not upload the ZIP as-is).
2. Open https://github.com/qvtrtran/qvtrtran.github.io
3. On the Code tab (branch main), select Add file > Upload files.
4. Open the extracted folder, select ALL files inside, and drag them to the GitHub upload window. They should appear at the TOP LEVEL (root) of your repository, not in a nested folder.
5. Press Commit changes.
6. After Pages deployment succeeds, visit https://qvtrtran.github.io and
   https://qvtrtran.github.io/publications.html. Refresh with Ctrl+Shift+R.

PROFILE PHOTO
This package intentionally does not overwrite profile.jpg because your
existing published website already shows your real portrait.
Keep the profile.jpg file that is already in your GitHub repository.
If you ever create a new repository from scratch, upload your photo as profile.jpg.

NOTE

- The existing condensed public CV PDF is supplied unchanged. Review its
  contents for accuracy and confidentiality before publishing; it may list submitted manuscripts.
- Check that you have rights to display the supplied research figures publicly.
