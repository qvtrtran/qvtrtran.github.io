## Add your profile photo
1. Choose a clear portrait photo. Crop it to a roughly square composition with your face centered.
2. Save/export the photo as a JPG named **profile.jpg** (exact spelling, all lowercase). Recommended resolution: 600×600 to 1200×1200 pixels; ideally under 1 MB.
3. Upload `profile.jpg` to the **root** of your GitHub Pages repository (beside `index.html`). Do **not** put it inside another folder. The image will automatically replace the QV placeholder on **Home, Publications, and CV**.
4. If the picture does not load, check capitalization, extension (.jpg, not .jpeg or .png), and GitHub Pages deployment completion. The QV initials remain visible if `profile.jpg` is missing.

## Update the site
1. Upload **index.html**, **publications.html**, and **cv.html** to the repository root, replacing the old versions. Also upload `profile.jpg` when you have it.
2. Commit changes on the `main` branch. The PDF in this bundle is the prior public CV, unchanged.
3. Wait for GitHub Pages to deploy, then hard refresh the pages (Ctrl+Shift+R).
